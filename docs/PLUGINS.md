# 插件与音乐源

桌面端和安卓端共用木听风的纯 Go JavaScript/TypeScript 插件宿主。各插件按需启动，支持异步调用、超时中断、权限、配置与持久化存储。木听风可加载采用兼容 `plugin.json` 和宿主接口的第三方插件。

## 安装与使用

1. 打开「设置 → 插件」，点击右上角 `+` 菜单选择「从 GitHub…」「从文件夹…」（桌面端）或「从 Zip 文件…」，也可以在「插件源订阅」中输入 JSON 插件清单网址。
2. 查看插件名称、版本和网络权限，再确认安装。安装仅载入代码，首次使用才运行插件。
3. 桌面端点击侧栏顶部的音乐源名称切换；手机在「音乐库 → 音乐源」切换，使用插件时也可从顶部下拉按钮切换。
4. 在已安装插件卡片中配置参数（支持文本自动保存、密码掩码与确认保存、开关与下拉选项）、启用或停用插件、授予桌面程序权限。插件提供登录方法时，可直接在卡片中登录或退出。
5. 已安装的远程插件与已订阅的插件源会在后台按每 24 小时节流静默检查更新，也可以在插件页右上角或单个插件的 `⋯` 菜单手动检查。所有更新提示、更新操作和新增权限确认均集中在「设置 → 插件」页内完成，不弹出打扰性的更新窗口。移除插件会保留其配置和登录数据，重新安装相同 ID 后可继续使用。

## 插件源订阅（JSON 清单）

在「设置 → 插件 → 插件源订阅」输入 `https://` JSON 清单地址即可订阅第三方插件源（本地开发支持 `http://127.0.0.1`）。清单支持通过 GitHub 仓库或带 `sha256` 校验的直链 ZIP 分发：

```json
{
  "name": "Example Catalog",
  "description": "Community pure-JS sources",
  "plugins": [
    {
      "id": "demo-gh",
      "name": "Demo GitHub Plugin",
      "repo": "owner/repo",
      "version": "1.0.0",
      "pureJs": true,
      "description": "Installed from GitHub release or pinned commit"
    },
    {
      "id": "demo-zip",
      "name": "Demo Direct ZIP Plugin",
      "version": "1.2.0",
      "downloadUrl": "https://example.com/demo-1.2.0.zip",
      "sha256": "<64-hex-sha256>",
      "platforms": ["desktop", "android"]
    }
  ]
}
```

来自订阅源的插件检查更新时会优先读取该源 JSON，避免消耗 GitHub 匿名 API 限额。

「设置 → 插件 → 兼容的第三方插件」展示原作者仓库、许可证、验证版本和实测范围。点安装后从作者仓库下载对应提交的原始源码，并显示权限供确认。木听风发行包只包含条目信息。插件代码按作者仓库的许可证提供，歌曲、歌词和封面的使用遵循各自权利人的授权及服务条款。

支持账号的音源登录后，桌面侧栏底部显示头像和昵称，点击打开「我的主页」（插件提供时）、「设置」和「退出登录」菜单；未登录时显示该音源的登录入口。重启后自动读取插件保存的账号，切换音源时分别保留账号状态。插件设置中显示当前登录的昵称，并按登录状态提供登录或退出操作；从设置登录另一个音源后，会切换到该音源。手机音乐库内也可查看和操作当前音源账号。

也可以把插件目录放进应用数据目录下的 `plugins/<插件 ID>/`，重启应用后发现。开发示例位于 [`examples/demo-plugin`](../examples/demo-plugin)，无需网络，包含歌曲、歌词、歌单、播客、电台和评论。

## 可用功能

插件导出的能力决定导航内容。已接入插件首页与自定义页面、歌曲/歌手/专辑/歌单/播客搜索、搜索分页、歌词与音质、收藏歌曲、歌单编辑、收藏专辑和歌单、关注歌手、播客订阅和节目分页、电台连续播放、评论分页/点赞/发布，以及远程播放源的现有播放控制。

切换音乐源时清除页面缓存，旧请求不会覆盖新音源的搜索结果；正在播放的队列仍通过歌曲自己的音源解析。页面历史和手机三个导航入口都保留音源身份。缺失的插件不会回退到本地音源。

插件的 `requestHeaders` 可以为指定主机的封面和音频附加凭据。封面由宿主读取。插件音频由应用管理下载，桌面和安卓的 NSGo 播放器通过本机回环地址读取音频范围。访问地址使用随机凭证，切歌或清空播放时释放。重定向到其他主机时移除鉴权头。

## 平台边界

- 安卓插件应使用纯 JS/TS 和网络接口。依赖桌面可执行程序的插件不能在安卓运行；桌面端则需在插件设置中明确允许其启动程序。
- 当前支持插件自身的扫码及浏览器回调登录。NSGo 尚未提供隔离网页会话和读取 HttpOnly Cookie 的公共接口，因此暂不声明 `host.webSignIn` 能力，让支持能力检测的插件自动退回扫码登录。不能将普通 WebView 中的 `document.cookie` 视为等价实现。
- 桌面和安卓使用各自的系统解码器，格式与倍速音调表现取决于平台。已存音乐与自动缓存供两端的原生播放链路使用。
- GitHub 单插件安装、JSON 插件源订阅、每 24 小时静默更新检查（仅在插件设置页内提示，不做弹窗更新）与远程播放控制已经可用。远程设备选择界面尚未接入。
- 插件与实际服务的兼容性取决于插件本身。构建与集成测试不等于第三方服务登录或真机后台播放验收。

## 数据与验证

插件代码保存在应用数据目录的 `plugins/`，配置与存储保存在 `plugin-data/<ID>/`。面向木听风的插件可以在 `plugin.json` 中声明 `"minWoodwindVersion": "0.1.0"`。安装和加载时会与 NSGo 构建信息中的木听风版本比较。第三方插件的 `minAppVersion` 记录原宿主的版本要求。插件在木听风中的功能取决于实际使用的宿主接口和平台。

执行 `go run scripts/test-quiet.go ./internal/plugin` 和 `go run scripts/test-quiet.go ./internal/app` 验证插件宿主和界面，测试使用临时数据、空音频输出和无窗口环境。安卓完整打包使用 `go run ./cmd/android`。
