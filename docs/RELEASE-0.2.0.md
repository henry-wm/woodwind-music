# 木听风音乐 0.2.0

基于 **NSGo v0.3.0** 的功能与架构升级版本，继续同时提供 macOS Apple Silicon、Android arm64 和 Windows x64 下载。

## 自 0.1.0 以来的主要变化

### 已存音乐（独立离线资料库）
- 新增桌面侧栏与手机「音乐库 → 已存音乐」独立入口，统一管理自动缓存与「保留离线」歌曲。
- 支持按全部/保留离线/自动缓存筛选、本页搜索、歌曲/专辑/歌手浏览以及下载任务管理；断网、退出账号或移除原插件后，已完整保存的歌曲仍可独立播放。
- 自动纳入旧版 `songs/` 中的历史缓存，并支持在来源可用时补充缺失歌词与封面。详情见 [已存音乐说明](OFFLINE-MUSIC.md)。

### 播放、歌词与桌面体验
- **桌面歌词浮窗**：macOS 与 Windows 新增置顶透明桌面歌词浮窗（使用 NSGo 透明面板接口），支持逐字高亮、翻译/下一句显示、悬停播控、拖动定位与鼠标穿透锁定。
- **倍速播放**：桌面播放条、完整播放页和手机播放页支持 0.5×–2× 倍速选择，会话自动保存并在重启后恢复。
- **定时停止播放**：桌面与手机端新增睡眠定时（15–120 分钟预设与 1–1440 分钟自定义），到时暂停并保留队列与播放位置。
- **本地资料补齐**：播放本地曲库歌曲或缓存歌曲时，可通过已安装音乐源自动补齐缺失的同步歌词和封面并离线保存。
- **「我喜欢」与私人 FM**：完整读取音源全部分页收藏并同步红心状态；酷狗概念版私人 FM 按完整收藏与下载抽样并去重。

### Android 改进
- **目录直读免复制**：通过系统文档目录持久化授权（SAF）直接读取和流式播放原文件夹中的音频与 `.lrc` 歌词，不再把音乐文件复制到应用私有存储，并支持重新扫描增量变化。旧版已导入的私有副本仍可继续播放。
- **后台与熄屏播放修复**：适配 NSGo v0.3.0 视图生命周期，确保应用退回桌面和熄屏（`Dozing`）期间音频持续播放、进度正常推进、系统媒体控制与唤醒锁管理准确。

### 底层框架与插件兼容
- 升级至 **NSGo v0.3.0**：macOS 和 Windows 全面改用 NSGo `audio.Player` 解码与播放，接入框架的媒体、窗口和网络服务，大幅精简自维护音频代码。
- **插件解耦与内置目录**：插件最低版本改用 `minWoodwindVersion` 校验，原宿主 `minAppVersion` 不再阻断加载；设置中新增「兼容的第三方插件」目录，展示作者仓库、许可证与验证版本，按需下载源码。

## 数据与升级

发布包不包含任何第三方音乐源插件、个人账号、Cookie、登录凭据、曲库、播放历史或歌单；内置兼容目录仅含条目信息，插件代码按需从作者仓库下载。Android 已关闭备份。

覆盖安装保留本机曲库、歌单、已存音乐、插件与登录状态。三平台显示版本均为 `0.2.0`；内部构建号为 `200`，Android 可从 `0.1.0`（版本码 `131`）及私用 `0.1.30`（版本码 `130`）平滑覆盖升级，应用 ID 与签名保持不变。桌面升级前请先退出应用；请勿通过卸载或清除应用数据来升级。

## 已知限制

- **Windows（实验性支持）**：已完成交叉编译、静态检查、共享逻辑与托盘/设置模拟回归及打包审计，完整真机播放、安装升级、托盘与设备切换仍待验收，详见 [Windows 使用与验证](WINDOWS.md)。
- **Android 验收边界**：已在荣耀 GT（Android 16）验证覆盖升级、曲库会话保留、前台/后台与熄屏播放及系统媒体控制；真实蓝牙耳机切换、来电中断、整夜后台与首次 SAF 目录选择交互尚未在本次发版真机复测，详见 [0.2.0 发布验证](RELEASE-VALIDATION-0.2.0.md)。
- **格式与倍速音调**：ALAC、Ogg Vorbis 与碎片化 M4A 等格式兼容性，以及倍速时的音调表现，取决于平台系统播放器。桌面端已移除实时音频频谱。
- **插件与同步**：仓库订阅、插件自动更新检查、隔离网页 Cookie 登录、应用自动更新、双击文件关联与跨设备同步尚未接入。

构建源码需要 Go 1.27.3+。完整用法、构建流程与验证边界见 README 与平台文档。
